# Процесс разработки

## Git

- Ветки: `main` (стабильная), `feature/*`, `fix/*`.
- Коммиты: conventional commits (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`).
- Не коммитить без явного запроса пользователя.
- Не коммитить секреты, ключи, `.env`.

## Pre-commit проверки

Перед коммитом запускать:

```bash
make lint
make typecheck
make test
```

Все три должны проходить. Если что-то падает — исправить перед коммитом.

## Порядок работы

1. Изучи контекст: используй поиск по коду, читай соседние файлы.
2. Следуй существующим паттернам в коде (импорты, именование, структура).
3. После изменений запускай `make lint && make typecheck && make test`.
4. Не коммить без явного запроса пользователя.
