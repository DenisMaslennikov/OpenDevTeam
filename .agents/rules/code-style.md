# Конвенции кода

## Python

- **Python 3.14** — целевая версия для всех пакетов.
- Стиль: `ruff` (lint + format). Конфиг в корневом `pyproject.toml`.
- Длина строки: **120 символов**.
- Типизация: строгая, `mypy`. Все публичные функции имеют type hints.
- Импорты: абсолютные, сортировка через `ruff isort`.
- Имена: `snake_case` для функций/переменных, `PascalCase` для классов, `UPPER_SNAKE` для констант.
- Документация: docstrings на все публичные классы и функции (Google style).
- **Без комментариев в коде**, если не запрошено явно. Код должен быть самодокументируемым.

## Frontend

- **TypeScript** строгий режим.
- **React 19** + Ant Design 6.
- Имена: `PascalCase` для компонентов, `camelCase` для функций/переменных.
- Импорты: абсолютные через alias `@/*` → `src/*`.
